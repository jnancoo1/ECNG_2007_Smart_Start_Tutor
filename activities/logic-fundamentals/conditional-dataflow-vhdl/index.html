Revisiting the Two-Input AND Gate

An AND gate has two inputs and one output. Its output is '1' only when both inputs are '1'. 

Y <= A and B;

AND Gate Truth Table

A B Y
000
010
100
111

Grouping Signals Into a Vector

Instead of declaring A and B separately, we can group them into one vector called I. 

library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity and_gate is
    port (
        I : in std_logic_vector(1 downto 0);
        Y : out std_logic
    );
end entity and_gate;
I(1) Previous input A
I(0) Previous input B

Direct Dataflow

architecture direct_dataflow of and_gate is
begin
    Y <= I(1) and I(0);
end architecture direct_dataflow;

Scalar Values and Vector Values

'1' Scalar

One std_logic element.

"01" Vector

Two std_logic elements.

Try Reading a Vector

I(1) = '0' and I(0) = '0'.

The Nine std_logic States

'0'Logic zero
'1'Logic one
'U'Uninitialised
'X'Unknown
'Z'High impedance
'W'Weak unknown
'L'Weak zero
'H'Weak one
'-'Don't care
Important

'X' means unknown. It does not mean don't-care. The don't-care value is '-'.

02 · EXPLORE

Conditional Dataflow

We can describe the AND gate by examining the complete input vector and selecting an output value.

Method 1: when ... else

architecture conditional_when_else of and_gate is
begin
    Y <= '1' when I = "11" else
         '0' when I = "00" or I = "01" or I = "10" else
         'X';
end architecture conditional_when_else;

Method 2: with ... select

architecture conditional_with_select of and_gate is
begin
    with I select
        Y <= '0' when "00",
             '0' when "01",
             '0' when "10",
             '1' when "11",
             'X' when others;
end architecture conditional_with_select;
Why use when others?

It handles every input value that was not explicitly listed, including vectors containing unknown states.

Compare the Three Descriptions

Description Main Idea
Direct dataflow State the logical relationship.
when ... else Test a sequence of conditions.
with ... select Select an output for each input.

Create a Three-Input Equality Detector

The circuit has one three-element input vector I and one output Y.

The output should be '1' when all three binary input elements have the same value. 

library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity equality_detector is
    port (
        I : in std_logic_vector(2 downto 0);
        Y : out std_logic
    );

KEY IDEAS

What You Should Understand

  • A std_logic_vector groups multiple std_logic elements.
  • Individual elements are accessed using an index.
  • Scalar values use single quotation marks.
  • Vector values use double quotation marks.
  • when ... else tests conditions in order.
  • with ... select lists input choices.
  • when others handles unlisted values.
  • Neither conditional assignment requires a process.
